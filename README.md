# Task Manager (Bash)

A CLI-based Task Manager built using Bash.

## Features
- Add, Update, Delete Tasks
- Filter by Status and Priority
- Overdue Detection
- Input Validation
- Colored Terminal Output

## Technologies Used
- awk
- sed
- grep
- date
- ANSI escape codes

## Data Format
ID|Title|Priority|DueDate|Status

## Run the Script
```bash
bash task_manager.sh
